# Student Record Manager

## About
A beginner Java console application created to practise programming fundamentals and basic student record management.

## Features
- Add student names
- Display saved names during the current program session
- Menu-driven interface
- Basic input handling

## Technologies Used
- Java
- ArrayList
- Scanner
- Loops and switch statements

## How to Run
1. Install the Java Development Kit (JDK).
2. Download `StudentRecordManager.java`.
3. Open a terminal in the file's directory.
4. Run `javac StudentRecordManager.java`.
5. Run `java StudentRecordManager`.

## Learning Objectives
- Practise Java syntax and control flow
- Accept user input using Scanner
- Store data using an ArrayList

## Project Status
Beginner practice project.
